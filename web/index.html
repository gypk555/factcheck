    How XFND-CLIP works

    It reads a post's headline and the image shared with it, decides whether the post is fake, and explains why.

    1. 1. Input

      Claim text
      Image (optional)

    2. 2. Frozen encoders

      BERT 768-d text meaning
      ResNet-50 2048-d image content
      CLIP ViT-B/32 text + image in one space

    3. 3. Three branches

      Text branch
      Image branch
      Text-image branch agreement, |t−i|, t×i

    4. 4. Attention

      Weights each branch knows if the image is missing

    5. 5. Verdict

      FAKE or REAL with P(fake)

    Only the small fusion network is trained; the big encoders stay frozen, so training fits on a free Colab GPU.

    How it explains a decision

    Word importance

    Each word is removed in turn. If the fake score drops, that word was pushing towards fake.

    Grad-CAM heatmap

    Traces the fake decision back through ResNet-50 to the image regions that drove it.

    Modality weights

    The attention scores: how much the text, the image and their agreement counted.

    CLIP similarity

    Measures whether the picture fits the headline. Real photos reused with false captions often fit poorly.

    What is new compared with the base paper

    Base paper: Zhou et al., "Multimodal Fake News Detection via CLIP-Guided Learning", IEEE ICME 2023 (FND-CLIP).

    1. Cross-modal consistency features. The difference and product of the CLIP text and image embeddings show where text and image disagree.
    2. Availability-aware attention. The model knows when an image is missing (many IFND image links are dead) and relies on the text instead.
    3. Class-balanced focal loss for the remaining class imbalance.
    4. Explanation module. The base paper only outputs real or fake; XFND-CLIP shows why.

    Data

    IFND, an Indian fake news dataset (Sharma & Garg, 2023): about 37.8k real and 7.3k fake headlines with images. All fake items are kept and real items sampled, then split 70/15/15 into train, validation and test.

    Limits

    The model learns patterns in its training data. It does not check facts, and it struggles with new events: it agreed with fact-checkers on only 2 of 5 recent posts (see Results).
