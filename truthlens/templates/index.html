        How TruthLens works, and where it fails

        News text

        Words and word pairs are scored (TF-IDF) and combined by a Logistic Regression model trained on {{ "{:,}".format(meta.get('train_examples', 0)) }} examples from the WELFake dataset. Each highlighted word's colour is its exact share of the score.

        {% set t = meta.get('test_metrics', {}) %}{% set l = meta.get('liar2_metrics', {}) %}
        Unseen news articles
        {{ "%.1f"|format(t.get('accuracy', 0) * 100) }}%
        Short political claims (LIAR2)
        {{ "%.1f"|format(l.get('accuracy', 0) * 100) }}%

        It judges how a text is written, not whether it is true. On short political claims it is no better than guessing.

        Images

        AI fingerprint: a small neural network trained on real photos and AI-generated images; the heatmap shows the regions that raised the score. {% if not image_models.ai %}Not installed on this server yet.{% endif %}

        Edit map: Error Level Analysis re-saves the image and shows areas that compress differently, which often means they were added or changed. {% if not image_models.edit %}The edit-probability model isn't installed yet, so only the map is shown.{% endif %}

        Re-shared images are compressed, which hides traces. New AI generators can fool the detector. Treat results as a signal, not proof.
